# Minha API

Este pequeno projeto é um pequeno projeto MVP, desenvolvimento como uma forma de praticar o Back-End e o Front-End, com a tematica de livros.

O objetivo é criar um pequeno cadastro de livros em um site.

---
## Como executar 

Será necessário ter todas as libs python listadas no `requirements.txt` instaladas para executar o arquivo

> Para esse projeto, não é necessário executar o ambiente virtual, só executando o arquivo principal (app.py) no terminal já funciona. Mas é bom o uso de ambientes virtuais como [virtualenv](https://virtualenv.pypa.io/en/latest/installation.html).

```
(env)$ pip install -r requirements.txt
```

Este comando instala as dependências/bibliotecas, descritas no arquivo `requirements.txt`.

Para executar a API basta executar:

Abra o arquivo, em seguida abra o terminal, depois digite "cd ./Back-End" para entrar na pasta do Back-End, e em 
seguida, execute o arquivo digitando no terminal:'python app.py', em seguida arraste o mouse em cima do server (http://127.0.0.1:5000) no terminal e clique no link azul acima (Follow link(ctrl + click)). Quando a página do navegador se abrir, coloque o endereço completo: http://127.0.0.1:5000/docs, e por último, clique em cima do Swagger para executá-lo

Abra o [http://localhost:5000/#/](http://127.0.0.1:5000) no terminal e clique no link, em seguida no navegador,
escreva 'docs' e assim abrirá o Swagger, e por ultimo, clique no Swagger para verificar a API em execução.
